nano main.tf :Opening a terminal-based text editor
→ Writing Terraform code directly in Linux/WSL/Cloud shell                               

Inside nano:

Action	Key
Save file	CTRL + O
Confirm save	ENTER
Exit editor	CTRL + X

1. Open terminal
2. Create folder
3. Open nano editor
4. Write Terraform code
5. Save file
6. Run terraform init → plan → apply
7. Create EC2 in AWS Mumbai
8. Destroy when done
